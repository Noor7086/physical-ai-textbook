# NVIDIA Isaac Sim

NVIDIA Isaac Sim is the flagship robotics simulator within the NVIDIA Omniverse ecosystem. It provides photorealistic rendering, physically accurate simulation, and tight integration with AI/ML frameworks -- making it the tool of choice for developing humanoid robots at scale.

## Learning Objectives

By the end of this chapter, you will be able to:

1. **Install** Isaac Sim and navigate the Omniverse Launcher
2. **Understand** USD (Universal Scene Description) and create robot scenes
3. **Configure** PhysX 5 physics parameters for articulated robots
4. **Use** the Isaac Sim Python API to programmatically control simulations
5. **Build** GPU-accelerated simulation pipelines
6. **Set up** Isaac Lab for structured reinforcement learning experiments

## Installation and Setup

### System Requirements

Isaac Sim requires an NVIDIA RTX GPU and Ubuntu 22.04. Verify your system is ready:

```bash
# Check NVIDIA driver version (requires 525.60+ for Isaac Sim 4.x)
nvidia-smi

# Check CUDA version
nvcc --version

# Verify GPU is RTX series
nvidia-smi --query-gpu=name --format=csv,noheader
```

The recommended installation path uses the NVIDIA Omniverse Launcher:


## The Omniverse Platform

Isaac Sim is built on **NVIDIA Omniverse**, a platform for building and operating 3D applications. Understanding Omniverse fundamentals is essential for effective use of Isaac Sim.

### Omniverse Architecture

```
┌─────────────────────────────────────────────────────┐
│                  Isaac Sim Application                │
├──────────────┬──────────────┬───────────────────────┤
│  Extensions   │  Python API  │  ROS 2 Bridge         │
├──────────────┴──────────────┴───────────────────────┤
│                Omniverse Kit SDK                      │
├─────────────┬───────────────┬───────────────────────┤
│  USD Stage  │  RTX Renderer │  PhysX 5 Engine       │
├─────────────┴───────────────┴───────────────────────┤
│                   NVIDIA GPU / CUDA                   │
└─────────────────────────────────────────────────────┘
```

### Key Omniverse Concepts

| Concept | Description |
|---|---|
| **Stage** | The root container for all scene data, stored as USD |
| **Prim** | A primitive -- any object in the scene (mesh, light, camera, robot) |
| **Extension** | A modular plugin that adds functionality to the application |
| **Connector** | A bridge between Omniverse and external tools (Blender, Maya, ROS) |
| **Nucleus** | A collaboration server for sharing and versioning USD assets |

## Universal Scene Description (USD)

**USD** is the foundational file format of Isaac Sim. Originally developed by Pixar for film production, USD has become the standard interchange format for 3D content in robotics and digital twins.

### Why USD Matters for Robotics

- **Composable**: Assemble complex scenes from reusable parts
- **Layered**: Override properties without modifying the original asset
- **Scalable**: Handle scenes with millions of prims efficiently
- **Interoperable**: Share assets across tools and platforms

### Creating a Scene Programmatically

```python
from isaacsim import SimulationApp
simulation_app = SimulationApp({"headless": False})

import omni.isaac.core.utils.stage as stage_utils
from omni.isaac.core import World
from omni.isaac.core.objects import DynamicCuboid, FixedCuboid
from omni.isaac.core.utils.prims import create_prim
import numpy as np

# Create the world
world = World(stage_units_in_meters=1.0)

# Add a ground plane
world.scene.add_default_ground_plane()

# Add a table (fixed object)
table = world.scene.add(
    FixedCuboid(
        prim_path="/World/Table",
        name="table",
        position=np.array([0.5, 0.0, 0.4]),
        scale=np.array([0.8, 0.6, 0.02]),
        color=np.array([0.5, 0.3, 0.1]),  # Brown
    )
)

# Add a box on the table (dynamic object affected by physics)
box = world.scene.add(
    DynamicCuboid(
        prim_path="/World/Box",
        name="box",
        position=np.array([0.5, 0.0, 0.5]),
        scale=np.array([0.05, 0.05, 0.05]),
        color=np.array([1.0, 0.0, 0.0]),  # Red
        mass=0.1,  # 100 grams
    )
)

# Initialize and run the simulation
world.reset()

for step in range(1000):
    world.step(render=True)
    
    if step % 100 == 0:
        position, orientation = box.get_world_pose()
        velocity = box.get_linear_velocity()
        print(f"Step {step}: pos={position}, vel={velocity}")

simulation_app.close()
```

## PhysX 5 Physics Engine

Isaac Sim uses **NVIDIA PhysX 5**, a GPU-accelerated physics engine purpose-built for robotics simulation. PhysX 5 introduces critical features for humanoid robots.

### Key PhysX 5 Features for Robotics

| Feature | Description | Humanoid Use Case |
|---|---|---|
| **GPU Rigid Bodies** | Parallel rigid body simulation on GPU | Full-body dynamics |
| **Articulations** | Efficient reduced-coordinate joint chains | Kinematic chains (limbs) |
| **TGS Solver** | Temporal Gauss-Seidel iterative solver | Stable contact resolution |
| **Soft Bodies** | FEM-based deformable simulation | Soft skin, padding |
| **Tendons** | Spatial and fixed tendon constraints | Coupled joints, underactuation |
| **Contact Reporting** | Detailed contact force data | Foot-ground interaction |

### Configuring Physics Parameters

```python
from omni.isaac.core import World
from pxr import UsdPhysics, PhysxSchema

world = World(
    physics_dt=1.0 / 500.0,    # 500 Hz physics (good for contact-rich tasks)
    rendering_dt=1.0 / 60.0,   # 60 Hz rendering
    stage_units_in_meters=1.0,
)

# Access the physics scene to configure solver settings
stage = world.stage
physics_scene_path = "/physicsScene"
physics_scene = UsdPhysics.Scene.Get(stage, physics_scene_path)

# Configure PhysX-specific parameters
physx_scene = PhysxSchema.PhysxSceneAPI.Apply(stage.GetPrimAtPath(physics_scene_path))

# GPU dynamics for parallel simulation
physx_scene.GetEnableGPUDynamicsAttr().Set(True)

# Broadphase algorithm (GPU-optimized)
physx_scene.GetBroadphaseTypeAttr().Set("GPU")

# Solver iterations (higher = more accurate, slower)
physx_scene.GetGpuMaxRigidContactCountAttr().Set(524288)
physx_scene.GetGpuMaxRigidPatchCountAttr().Set(81920)

# Gravity
physics_scene.GetGravityDirectionAttr().Set((0.0, 0.0, -1.0))
physics_scene.GetGravityMagnitudeAttr().Set(9.81)

print("Physics configured for GPU-accelerated humanoid simulation")
```

### Articulation API for Humanoid Robots

The Articulation API provides efficient control of jointed robots:

```python
from omni.isaac.core.articulations import Articulation
import numpy as np

# Create an articulation handle for the humanoid
humanoid = Articulation(
    prim_path="/World/HumanoidRobot",
    name="humanoid",
)
world.scene.add(humanoid)
world.reset()

# Query robot properties
num_dof = humanoid.num_dof
joint_names = humanoid.dof_names
print(f"Humanoid has {num_dof} degrees of freedom")
print(f"Joint names: {joint_names}")

# Get current joint states
joint_positions = humanoid.get_joint_positions()
joint_velocities = humanoid.get_joint_velocities()
print(f"Joint positions: {joint_positions}")

# Set joint position targets (PD control)
target_positions = np.zeros(num_dof)
target_positions[0] = 0.5   # Bend the first joint
humanoid.set_joint_position_targets(target_positions)

# Configure joint stiffness and damping for PD control
stiffness = np.full(num_dof, 100.0)   # Nm/rad
damping = np.full(num_dof, 10.0)      # Nm*s/rad
humanoid.set_gains(kps=stiffness, kds=damping)

# Apply direct joint torques (for RL policies)
torques = np.zeros(num_dof)
torques[2] = 5.0  # Apply 5 Nm to joint index 2
humanoid.set_joint_efforts(torques)

# Step the simulation
for i in range(1000):
    world.step(render=True)
```

## The GPU Simulation Pipeline

Understanding the GPU pipeline is critical for achieving maximum simulation throughput.

### Data Flow Architecture

```
┌────────────────────────────────────────────────────────┐
│                     GPU Memory                          │
│                                                        │
│  ┌──────────┐    ┌──────────┐    ┌──────────────────┐ │
│  │ PhysX 5  │───▶│ State    │───▶│ Neural Network   │ │
│  │ Engine   │    │ Buffers  │    │ (Policy/Value)   │ │
│  └──────────┘    └──────────┘    └──────────────────┘ │
│       ▲                               │               │
│       │          ┌──────────┐         │               │
│       └──────────│ Action   │◀────────┘               │
│                  │ Buffers  │                          │
│                  └──────────┘                          │
│                                                        │
│  ┌──────────────────────────────────────────────────┐ │
│  │        Parallel Environments (4096+)              │ │
│  │  ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐    │ │
│  │  │E0 │ │E1 │ │E2 │ │E3 │ │...│ │...│ │En │    │ │
│  │  └───┘ └───┘ └───┘ └───┘ └───┘ └───┘ └───┘    │ │
│  └──────────────────────────────────────────────────┘ │
│                                                        │
│  Zero CPU-GPU data transfer during training loop       │
└────────────────────────────────────────────────────────┘
```

### Batched Environment Example

```python
import torch
from isaacsim import SimulationApp

simulation_app = SimulationApp({"headless": True})

from omni.isaac.core import World
from omni.isaac.core.articulations import ArticulationView
from omni.isaac.cloner import GridCloner
import numpy as np

NUM_ENVS = 4096
ENV_SPACING = 2.0

world = World(physics_dt=1.0 / 200.0, rendering_dt=1.0 / 60.0)

# Use GridCloner to create parallel environments efficiently
cloner = GridCloner(spacing=ENV_SPACING)
cloner.define_base_env("/World/envs")

# Define the base environment with a robot
prim_paths = cloner.generate_paths("/World/envs/env", NUM_ENVS)
env_positions = cloner.clone(
    source_prim_path="/World/envs/env_0",
    prim_paths=prim_paths,
)

# Create an ArticulationView for batched operations on all robots
robots = ArticulationView(
    prim_paths_expr="/World/envs/env_.*/Robot",
    name="humanoid_robots",
)
world.scene.add(robots)
world.reset()

# Now all robots can be controlled in a single batched operation
num_dof = robots.num_dof
print(f"Managing {NUM_ENVS} robots with {num_dof} DOF each")

# Get all joint positions as a single GPU tensor [NUM_ENVS, num_dof]
all_positions = robots.get_joint_positions()
print(f"Joint positions tensor shape: {all_positions.shape}")

# Apply random actions to all robots simultaneously
random_actions = torch.randn(NUM_ENVS, num_dof, device="cuda") * 10.0
robots.set_joint_efforts(random_actions)

# Step all environments at once
for step in range(1000):
    world.step(render=False)

print(f"Simulated {NUM_ENVS} robots for 1000 steps on GPU")
simulation_app.close()
```

### Defining an Isaac Lab Environment

```python
import isaaclab.sim as sim_utils
from isaaclab.envs import ManagerBasedRLEnv, ManagerBasedRLEnvCfg
from isaaclab.scene import InteractiveSceneCfg
from isaaclab.assets import ArticulationCfg, AssetBaseCfg
from isaaclab.managers import ObservationGroupCfg, ObservationTermCfg
from isaaclab.managers import RewardTermCfg, TerminationTermCfg
import isaaclab.envs.mdp as mdp
from dataclasses import MISSING

# Define the scene configuration
class HumanoidSceneCfg(InteractiveSceneCfg):
    """Configuration for the humanoid robot scene."""

    # Ground plane
    ground = AssetBaseCfg(
        prim_path="/World/GroundPlane",
        spawn=sim_utils.GroundPlaneCfg(),
    )

    # Humanoid robot articulation
    robot = ArticulationCfg(
        prim_path="{ENV_REGEX_NS}/Robot",
        spawn=sim_utils.UsdFileCfg(
            usd_path="path/to/humanoid.usd",
            rigid_props=sim_utils.RigidBodyPropertiesCfg(
                disable_gravity=False,
                max_depenetration_velocity=10.0,
            ),
            articulation_props=sim_utils.ArticulationRootPropertiesCfg(
                enabled_self_collisions=True,
                solver_position_iteration_count=4,
                solver_velocity_iteration_count=0,
            ),
        ),
        init_state=ArticulationCfg.InitialStateCfg(
            pos=(0.0, 0.0, 1.05),  # Standing height
            joint_pos={".*": 0.0},  # All joints at zero
        ),
    )

    # Lighting
    light = AssetBaseCfg(
        prim_path="/World/Light",
        spawn=sim_utils.DistantLightCfg(intensity=3000.0),
    )


# Define the full environment configuration
class HumanoidEnvCfg(ManagerBasedRLEnvCfg):
    """Configuration for the humanoid standing/walking environment."""

    # Scene
    scene = HumanoidSceneCfg(num_envs=4096, env_spacing=2.5)

    # Observation space
    observations = ObservationGroupCfg(
        policy=ObservationGroupCfg(
            joint_pos=ObservationTermCfg(func=mdp.joint_pos_rel),
            joint_vel=ObservationTermCfg(func=mdp.joint_vel_rel),
            base_lin_vel=ObservationTermCfg(func=mdp.base_lin_vel),
            base_ang_vel=ObservationTermCfg(func=mdp.base_ang_vel),
            projected_gravity=ObservationTermCfg(func=mdp.projected_gravity),
        ),
    )

    # Action space (joint position targets)
    actions = mdp.JointPositionActionCfg(
        asset_name="robot",
        joint_names=[".*"],
        scale=0.5,
    )

    # Rewards
    rewards = {
        "alive": RewardTermCfg(func=mdp.is_alive, weight=2.0),
        "forward_velocity": RewardTermCfg(
            func=mdp.base_lin_vel,
            weight=1.0,
            params={"asset_cfg": SceneEntityCfg("robot"), "target_vel": 1.0},
        ),
        "joint_torques": RewardTermCfg(
            func=mdp.joint_torques_l2,
            weight=-0.0001,
        ),
    }

    # Termination conditions
    terminations = {
        "fall": TerminationTermCfg(
            func=mdp.base_height,
            params={"minimum_height": 0.5},
        ),
        "time_out": TerminationTermCfg(
            func=mdp.time_out,
            time_out=True,
        ),
    }
```

### Running an Isaac Lab Environment

```python
from isaaclab.envs import ManagerBasedRLEnv

# Create the environment
env = ManagerBasedRLEnv(cfg=HumanoidEnvCfg())

# Reset all environments
obs, info = env.reset()
print(f"Observation shape: {obs['policy'].shape}")  # [4096, obs_dim]

# Run a simple random policy loop
for step in range(10000):
    # Sample random actions
    actions = torch.randn(env.num_envs, env.action_space.shape[1], device=env.device)

    # Step the environment
    obs, rewards, terminated, truncated, info = env.step(actions)

    if step % 1000 == 0:
        print(f"Step {step}: mean reward = {rewards.mean().item():.4f}")

env.close()
```

## Working with Cameras and Sensors

Isaac Sim provides physically accurate sensor simulation:

```python
from omni.isaac.sensor import Camera, ContactSensor, IMUSensor
import numpy as np

# Add a camera to the robot's head
head_camera = Camera(
    prim_path="/World/HumanoidRobot/head_link/Camera",
    frequency=30,
    resolution=(640, 480),
)
head_camera.initialize()

# Configure camera for RGB + Depth
head_camera.add_motion_vectors_to_frame()
head_camera.add_distance_to_image_plane_to_frame()

# Add IMU sensor to the torso
imu = IMUSensor(
    prim_path="/World/HumanoidRobot/torso_link/IMU",
    name="torso_imu",
    frequency=200,
    translation=np.array([0.0, 0.0, 0.0]),
)

# Add contact sensors to feet
left_foot_contact = ContactSensor(
    prim_path="/World/HumanoidRobot/left_foot_link/ContactSensor",
    name="left_foot_contact",
    min_threshold=0.1,
    max_threshold=1000.0,
    radius=0.05,
)

# During simulation, read sensor data
world.reset()
for step in range(500):
    world.step(render=True)

    if step % 30 == 0:
        # Get camera image
        rgb = head_camera.get_rgba()
        depth = head_camera.get_depth()
        print(f"RGB shape: {rgb.shape}, Depth range: [{depth.min():.2f}, {depth.max():.2f}]")

        # Get IMU reading
        imu_data = imu.get_current_frame()
        print(f"IMU linear accel: {imu_data['lin_acc']}")
        print(f"IMU angular vel:  {imu_data['ang_vel']}")
```

## Common Isaac Sim Patterns

### Resetting Specific Environments

```python
# In parallel simulation, reset only environments that terminated
terminated_envs = torch.where(terminated)[0]

if len(terminated_envs) > 0:
    # Reset positions for terminated environments
    default_pos = torch.zeros(len(terminated_envs), 3, device="cuda")
    default_pos[:, 2] = 1.05  # Standing height

    robots.set_world_poses(
        positions=default_pos,
        indices=terminated_envs,
    )

    # Reset joint states
    robots.set_joint_positions(
        positions=torch.zeros(len(terminated_envs), num_dof, device="cuda"),
        indices=terminated_envs,
    )
    robots.set_joint_velocities(
        velocities=torch.zeros(len(terminated_envs), num_dof, device="cuda"),
        indices=terminated_envs,
    )
```
