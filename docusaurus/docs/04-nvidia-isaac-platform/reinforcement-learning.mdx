# Reinforcement Learning for Robotics in Isaac

Reinforcement Learning (RL) has emerged as one of the most powerful methods for teaching humanoid robots to walk, balance, and manipulate objects. NVIDIA's **Isaac Gym** (now part of Isaac Lab) enables massively parallel GPU-accelerated training, running thousands of robot instances simultaneously. This chapter covers RL fundamentals for robotics, algorithm selection, reward design, and end-to-end training pipelines.

## Learning Objectives

By the end of this chapter, you will be able to:

1. **Explain** the RL problem formulation for robotics control
2. **Set up** Isaac Gym environments for humanoid locomotion training
3. **Compare** PPO and SAC algorithms and select the right one for your task
4. **Design** reward functions that produce stable, natural humanoid walking
5. **Configure** training pipelines with domain randomization
6. **Evaluate** trained policies and understand sim-to-real considerations

## RL Fundamentals for Robotics

In the RL framework, a robot (agent) interacts with its environment by observing states, taking actions, and receiving rewards. The goal is to learn a **policy** that maximizes cumulative reward.

```
┌──────────────────────────────────────────────────┐
│                 RL Training Loop                  │
│                                                  │
│   ┌─────────┐    action a_t    ┌─────────────┐  │
│   │  Policy  │────────────────▶│ Environment │  │
│   │  pi(a|s) │                 │ (Isaac Gym)  │  │
│   │          │◀────────────────│              │  │
│   └─────────┘  state s_{t+1}  └─────────────┘  │
│       ▲         reward r_t          │           │
│       │                             │           │
│       └─────────────────────────────┘           │
│              Gradient Update                    │
│                                                  │
│   Parallel: 4096 environments on one GPU         │
└──────────────────────────────────────────────────┘
```

### The MDP Formulation

| Component | Robotics Interpretation | Example (Humanoid Walking) |
|-----------|------------------------|---------------------------|
| **State s** | Joint positions, velocities, IMU, contacts | 60-dimensional vector |
| **Action a** | Joint torques or position targets | 20 joint targets |
| **Reward r** | Task performance signal | Forward velocity - energy cost |
| **Transition T** | Physics simulation step | Isaac Gym PhysX step at 200 Hz |
| **Discount gamma** | How much to value future rewards | 0.99 (long horizon) |

### Why GPU-Parallel Simulation Matters

```
Traditional RL (CPU):
  1 environment x 1000 steps/sec = 1,000 samples/sec
  Time to 1B samples: ~12 days

Isaac Gym (GPU):
  4096 environments x 1000 steps/sec = 4,096,000 samples/sec
  Time to 1B samples: ~4 minutes
```

This 4000x speedup transforms RL from impractical to practical for real robotics.

## PPO vs SAC: Algorithm Selection

The two most successful RL algorithms for robotics are **Proximal Policy Optimization (PPO)** and **Soft Actor-Critic (SAC)**.

| Feature | PPO | SAC |
|---------|-----|-----|
| **Type** | On-policy | Off-policy |
| **Sample efficiency** | Lower (needs fresh data) | Higher (reuses old data) |
| **GPU parallelism** | Excellent (batch collection) | Good (replay buffer) |
| **Stability** | Very stable training | Can be unstable early on |
| **Exploration** | Via policy entropy bonus | Built-in entropy maximization |
| **Hyperparameter sensitivity** | Low | Moderate |
| **Best for** | Locomotion, continuous control | Manipulation, dexterous tasks |
| **Isaac Gym default** | Yes | Supported |

## Reward Shaping for Humanoid Walking

Reward design is the most critical and nuanced part of RL for robotics. A poorly designed reward leads to unnatural gaits, unstable walking, or complete training failure.

### Reward Component Breakdown

```python
class HumanoidRewards:
    """Reward terms for humanoid locomotion training.

    The total reward is a weighted sum of individual terms:
        r_total = sum(w_i * r_i)

    Positive rewards encourage desired behavior.
    Negative rewards (penalties) discourage undesired behavior.
    """

    @staticmethod
    def forward_velocity(env, target_velocity=1.0):
        """Reward for matching the commanded forward velocity.

        This is the primary task reward. We use an exponential kernel
        to give partial credit for being close to the target.
        """
        forward_vel = env.robot.root_lin_vel_b[:, 0]  # x-velocity
        target = env.command_manager.get_command("velocity")[:, 0]
        error = torch.abs(forward_vel - target)
        return torch.exp(-error / 0.25)  # Weight: 1.0

    @staticmethod
    def lateral_velocity_penalty(env):
        """Penalize lateral (sideways) motion for straight walking."""
        lateral_vel = env.robot.root_lin_vel_b[:, 1]  # y-velocity
        return -torch.square(lateral_vel)  # Weight: 0.5

    @staticmethod
    def angular_velocity_penalty(env):
        """Penalize unwanted yaw rotation."""
        yaw_vel = env.robot.root_ang_vel_b[:, 2]  # z-angular velocity
        target_yaw = env.command_manager.get_command("velocity")[:, 2]
        error = torch.square(yaw_vel - target_yaw)
        return -error  # Weight: 0.5

    @staticmethod
    def upright_reward(env):
        """Reward for keeping the torso upright.

        Uses the z-component of the projected gravity vector.
        When perfectly upright, projected_gravity_z = -1.0.
        """
        gravity_z = env.robot.projected_gravity_b[:, 2]
        return (gravity_z + 1.0).clamp(min=0.0)  # Weight: 0.2

    @staticmethod
    def energy_penalty(env):
        """Penalize excessive joint torques to encourage efficiency.

        Humanoid walking should be energy-efficient, mimicking the
        passive dynamics of human gait.
        """
        torques = env.robot.joint_torques
        return -torch.sum(torch.square(torques), dim=-1)  # Weight: 0.001

    @staticmethod
    def action_smoothness_penalty(env):
        """Penalize rapid changes in action to produce smooth motions."""
        current = env.actions
        previous = env.previous_actions
        return -torch.sum(torch.square(current - previous), dim=-1)  # Weight: 0.01

    @staticmethod
    def joint_limit_penalty(env):
        """Penalize joints approaching their limits."""
        pos = env.robot.joint_pos
        lower = env.robot.joint_lower_limits
        upper = env.robot.joint_upper_limits
        margin = 0.1  # radians from limit

        below_lower = (pos < lower + margin).float()
        above_upper = (pos > upper - margin).float()
        violations = below_lower + above_upper
        return -torch.sum(violations, dim=-1)  # Weight: 0.1

    @staticmethod
    def foot_clearance_reward(env, target_height=0.04):
        """Reward for lifting the swing foot to avoid scuffing."""
        left_foot_height = env.robot.body_pos_w[:, env.foot_indices[0], 2]
        right_foot_height = env.robot.body_pos_w[:, env.foot_indices[1], 2]

        left_vel = torch.norm(env.robot.body_lin_vel_w[:, env.foot_indices[0], :2], dim=-1)
        right_vel = torch.norm(env.robot.body_lin_vel_w[:, env.foot_indices[1], :2], dim=-1)

        # Only reward clearance when the foot is moving (swing phase)
        left_reward = torch.where(
            left_vel > 0.1,
            torch.clamp(left_foot_height - target_height, min=0.0),
            torch.zeros_like(left_foot_height)
        )
        right_reward = torch.where(
            right_vel > 0.1,
            torch.clamp(right_foot_height - target_height, min=0.0),
            torch.zeros_like(right_foot_height)
        )
        return left_reward + right_reward  # Weight: 0.3


# Complete reward configuration with weights
REWARD_CONFIG = {
    "forward_velocity":          {"weight": 1.0,    "function": HumanoidRewards.forward_velocity},
    "lateral_velocity_penalty":  {"weight": 0.5,    "function": HumanoidRewards.lateral_velocity_penalty},
    "angular_velocity_penalty":  {"weight": 0.5,    "function": HumanoidRewards.angular_velocity_penalty},
    "upright_reward":            {"weight": 0.2,    "function": HumanoidRewards.upright_reward},
    "energy_penalty":            {"weight": 0.001,  "function": HumanoidRewards.energy_penalty},
    "action_smoothness":         {"weight": 0.01,   "function": HumanoidRewards.action_smoothness_penalty},
    "joint_limit_penalty":       {"weight": 0.1,    "function": HumanoidRewards.joint_limit_penalty},
    "foot_clearance":            {"weight": 0.3,    "function": HumanoidRewards.foot_clearance_reward},
}
```

### Reward Shaping Anti-Patterns

| Anti-Pattern | Problem | Better Approach |
|-------------|---------|-----------------|
| Sparse reward only (reach goal) | Agent never discovers the reward | Add shaping terms for sub-goals |
| Huge penalty for falling | Agent learns to stand still | Moderate penalty + velocity reward |
| Reward raw speed only | Unnatural, unstable gait | Add smoothness and energy terms |
| No action penalty | Jerky, oscillating motions | Penalize action magnitude and rate |
| Fixed target velocity | Cannot generalize to different speeds | Randomize velocity commands |

## Training Pipeline

### End-to-End Training Script

```python
import torch
from isaaclab.envs import ManagerBasedRLEnv
from isaaclab_rl.rsl_rl import PPORunner

def train_humanoid_locomotion():
    """Complete training pipeline for humanoid walking."""

    # Create the parallel environment
    env = ManagerBasedRLEnv(
        cfg=HumanoidLocomotionEnvCfg(),
        render_mode=None,  # Headless for training speed
    )
    print(f"Created {env.num_envs} parallel environments")
    print(f"Observation space: {env.observation_space}")
    print(f"Action space: {env.action_space}")

    # Create the PPO runner
    runner = PPORunner(
        env=env,
        cfg=HumanoidPPOCfg(),
        log_dir="./logs/humanoid_walk",
        device="cuda:0",
    )

    # Training loop
    print("Starting training...")
    runner.learn(
        num_learning_iterations=3000,
        init_at_random_ep_len=True,  # Stagger episode resets
    )

    # Save the trained policy
    runner.save("./checkpoints/humanoid_walk_final.pt")
    print("Training complete. Policy saved.")

    env.close()


if __name__ == "__main__":
    train_humanoid_locomotion()
```

### Training with Domain Randomization

```python
class DomainRandomizationCfg:
    """Randomization applied during training for robust policies."""

    # Physics randomization
    friction_range = (0.5, 1.5)        # Ground friction coefficient
    restitution_range = (0.0, 0.3)     # Bounciness
    added_mass_range = (-1.0, 3.0)     # kg added to torso

    # Motor randomization
    motor_strength_range = (0.8, 1.2)  # Scale factor on motor torques
    motor_offset_range = (-0.05, 0.05) # Joint position offset (rad)

    # Observation noise
    joint_pos_noise = 0.01             # rad standard deviation
    joint_vel_noise = 1.5              # rad/s standard deviation
    gravity_noise = 0.05               # Gravity direction noise

    # External disturbances
    push_interval_s = 8.0              # Apply random push every 8s
    push_velocity_range = (0.5, 1.5)   # m/s push magnitude

    # Terrain randomization
    terrain_types = ["flat", "rough", "slope", "stairs"]
    terrain_roughness_range = (0.0, 0.05)  # meters
    slope_range = (-0.2, 0.2)              # radians


def apply_randomization(env, cfg):
    """Apply domain randomization at episode reset."""
    num_envs = env.num_envs

    # Randomize friction
    friction = torch.empty(num_envs).uniform_(*cfg.friction_range)
    env.scene.set_ground_friction(friction)

    # Randomize robot mass
    added_mass = torch.empty(num_envs).uniform_(*cfg.added_mass_range)
    env.robot.set_added_mass(added_mass, body_name="torso")

    # Randomize motor strength
    motor_scale = torch.empty(num_envs, env.robot.num_joints).uniform_(
        *cfg.motor_strength_range
    )
    env.robot.set_motor_strength_scale(motor_scale)

    # Add observation noise
    env.robot.set_joint_pos_noise(cfg.joint_pos_noise)
    env.robot.set_joint_vel_noise(cfg.joint_vel_noise)
```

## Evaluating Trained Policies

```python
def evaluate_policy(checkpoint_path, num_episodes=100):
    """Evaluate a trained policy and compute performance metrics."""

    env = ManagerBasedRLEnv(
        cfg=HumanoidLocomotionEnvCfg(),
        render_mode="human",  # Enable visualization
    )

    # Load the trained policy
    policy = torch.jit.load(checkpoint_path).to("cuda:0")
    policy.eval()

    metrics = {
        "episode_rewards": [],
        "episode_lengths": [],
        "forward_velocities": [],
        "energy_costs": [],
        "fall_count": 0,
    }

    obs = env.reset()
    episode_reward = 0.0
    episode_length = 0

    for step in range(num_episodes * 1000):
        with torch.no_grad():
            actions = policy(obs)

        obs, rewards, dones, infos = env.step(actions)
        episode_reward += rewards.mean().item()
        episode_length += 1

        if dones.any():
            metrics["episode_rewards"].append(episode_reward)
            metrics["episode_lengths"].append(episode_length)
            metrics["fall_count"] += int(infos.get("fell", False))
            episode_reward = 0.0
            episode_length = 0

    # Compute summary statistics
    avg_reward = sum(metrics["episode_rewards"]) / len(metrics["episode_rewards"])
    avg_length = sum(metrics["episode_lengths"]) / len(metrics["episode_lengths"])
    fall_rate = metrics["fall_count"] / len(metrics["episode_rewards"])

    print(f"Evaluation Results ({num_episodes} episodes):")
    print(f"  Average reward:   {avg_reward:.2f}")
    print(f"  Average length:   {avg_length:.0f} steps")
    print(f"  Fall rate:        {fall_rate:.1%}")

    env.close()
    return metrics
```

## Summary

| Concept | Key Takeaway |
|---------|-------------|
| **RL for robotics** | Agent learns a policy mapping observations to actions by maximizing reward |
| **Isaac Gym** | GPU-parallel simulation enables 4096+ simultaneous environments |
