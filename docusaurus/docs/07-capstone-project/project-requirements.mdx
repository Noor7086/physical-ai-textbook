# Project Requirements

This document defines the complete requirements for the capstone project. Your goal is to build an **Autonomous Humanoid Assistant** capable of operating in a simulated indoor environment, receiving natural-language commands, and completing household tasks.

## Scenario Description

Your humanoid robot is deployed in a **simulated apartment** containing a living room, kitchen, and bedroom. A human operator issues voice or text commands such as:

- "Bring me the red cup from the kitchen counter."
- "Go to the bedroom and check if the window is open."
- "Pick up the book on the table and place it on the shelf."

The robot must **understand** the command, **plan** a sequence of actions, **navigate** to the correct location, **manipulate** the target object, and **report** the outcome back to the user.

## Functional Requirements

### FR-1: Natural Language Command Interface

The robot must accept commands through a text or speech interface and parse them into structured task representations.

```python
# Example: Command parsing node
from dataclasses import dataclass
from typing import Optional

@dataclass
class TaskCommand:
    """Structured representation of a user command."""
    action: str              # e.g., "fetch", "inspect", "place"
    target_object: str       # e.g., "red cup", "book"
    source_location: str     # e.g., "kitchen counter"
    destination: Optional[str] = None  # e.g., "shelf"
    
    def validate(self) -> bool:
        """Ensure command has minimum required fields."""
        return bool(self.action and self.target_object and self.source_location)


# Example parsed commands
commands = [
    TaskCommand(action="fetch", target_object="red cup", 
                source_location="kitchen counter", destination="user"),
    TaskCommand(action="inspect", target_object="window", 
                source_location="bedroom"),
    TaskCommand(action="place", target_object="book", 
                source_location="table", destination="shelf"),
]
```

**Acceptance Criteria:**
- [ ] Robot accepts free-form text commands via a ROS 2 topic (`/human_command`)
- [ ] Commands are parsed into structured `TaskCommand` messages
- [ ] Unknown or ambiguous commands trigger a clarification request
- [ ] Command history is logged for debugging

### FR-2: Autonomous Navigation

The robot must navigate between rooms and to specific locations within rooms using the ROS 2 Navigation Stack (Nav2).

```python
# Example: Navigation goal publisher
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseStamped
from nav2_simple_commander.robot_navigator import BasicNavigator

class HumanoidNavigator(Node):
    def __init__(self):
        super().__init__('humanoid_navigator')
        self.navigator = BasicNavigator()
        
        # Define known locations in the apartment
        self.locations = {
            'kitchen_counter': self._make_pose(3.0, 2.5, 0.0),
            'living_room_table': self._make_pose(0.0, 0.0, 0.0),
            'bedroom_window': self._make_pose(-2.0, 4.0, 1.57),
            'bookshelf': self._make_pose(1.0, -1.5, 3.14),
        }
    
    def navigate_to(self, location_name: str) -> bool:
        """Navigate to a named location. Returns True on success."""
        if location_name not in self.locations:
            self.get_logger().error(f'Unknown location: {location_name}')
            return False
        
        goal_pose = self.locations[location_name]
        self.navigator.goToPose(goal_pose)
        
        while not self.navigator.isTaskComplete():
            feedback = self.navigator.getFeedback()
            if feedback:
                remaining = feedback.distance_remaining
                self.get_logger().info(f'Distance remaining: {remaining:.2f}m')
        
        result = self.navigator.getResult()
        return result == self.navigator.TaskResult.SUCCEEDED
    
    def _make_pose(self, x: float, y: float, yaw: float) -> PoseStamped:
        pose = PoseStamped()
        pose.header.frame_id = 'map'
        pose.pose.position.x = x
        pose.pose.position.y = y
        pose.pose.orientation.z = yaw  # simplified; use quaternion in practice
        return pose
```

**Acceptance Criteria:**
- [ ] Robot can navigate to any named room in the apartment
- [ ] Obstacle avoidance works for static and dynamic obstacles
- [ ] Navigation succeeds in under 60 seconds for any room-to-room traversal
- [ ] Robot recovers from navigation failures (replanning)

### FR-5: Task Planning and Execution

The robot must decompose high-level commands into sequences of primitive actions and execute them reliably.

```python
# Example: Behaviour tree structure for a fetch task
"""
Fetch Task Behaviour Tree:

[Sequence: FetchObject]
├── [Action: ParseCommand]
├── [Action: NavigateToSource]
├── [Action: DetectObject]
├── [Fallback: GraspWithRetry]
│   ├── [Action: PlanGrasp]
│   ├── [Action: ExecuteGrasp]
│   └── [Action: RetryGrasp]  (max 3 attempts)
├── [Action: NavigateToDestination]
├── [Action: PlaceObject]
└── [Action: ReportSuccess]
"""

from dataclasses import dataclass
from enum import Enum
from typing import List

class TaskStatus(Enum):
    PENDING = "pending"
    RUNNING = "running"
    SUCCESS = "success"
    FAILURE = "failure"

@dataclass
class PrimitiveAction:
    name: str
    parameters: dict
    status: TaskStatus = TaskStatus.PENDING

class TaskPlanner:
    """Decomposes high-level commands into primitive action sequences."""
    
    def plan(self, command: 'TaskCommand') -> List[PrimitiveAction]:
        """Generate a sequence of primitive actions for a command."""
        actions = []
        
        if command.action == "fetch":
            actions = [
                PrimitiveAction("navigate", {"target": command.source_location}),
                PrimitiveAction("detect", {"object": command.target_object}),
                PrimitiveAction("grasp", {"object": command.target_object}),
                PrimitiveAction("navigate", {"target": command.destination}),
                PrimitiveAction("place", {"object": command.target_object}),
            ]
        elif command.action == "inspect":
            actions = [
                PrimitiveAction("navigate", {"target": command.source_location}),
                PrimitiveAction("detect", {"object": command.target_object}),
                PrimitiveAction("report", {"object": command.target_object}),
            ]
        
        return actions
    
    def execute(self, actions: List[PrimitiveAction]):
        """Execute actions sequentially, handling failures."""
        for action in actions:
            action.status = TaskStatus.RUNNING
            success = self._execute_single(action)
            action.status = TaskStatus.SUCCESS if success else TaskStatus.FAILURE
            
            if not success:
                return False
        return True
```

**Acceptance Criteria:**
- [ ] Robot decomposes at least 3 command types (fetch, inspect, place)
- [ ] Execution handles partial failures gracefully (retry or abort)
- [ ] Task progress is reported via a ROS 2 topic (`/task_status`)
- [ ] Average task completion time is under 120 seconds
