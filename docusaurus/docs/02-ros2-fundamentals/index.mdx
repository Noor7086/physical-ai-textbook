# ROS 2 Fundamentals

Welcome to **ROS 2** (Robot Operating System 2) - the industry-standard middleware for building robot software. This module covers Weeks 3-5 of the course.

## What is ROS 2?

ROS 2 is not an operating system in the traditional sense. It's a **middleware framework** that provides:

- **Communication Infrastructure** - Publish/subscribe messaging, services, actions
- **Hardware Abstraction** - Standard interfaces for sensors and actuators
- **Package Management** - Reusable software components
- **Tools and Utilities** - Visualization, debugging, simulation

```python
# A simple ROS 2 node in Python
import rclpy
from rclpy.node import Node

class MinimalNode(Node):
    def __init__(self):
        super().__init__('minimal_node')
        self.get_logger().info('Hello from ROS 2!')

def main():
    rclpy.init()
    node = MinimalNode()
    rclpy.spin(node)
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Why ROS 2 for Humanoids?

| Feature | Benefit for Humanoids |
|---------|----------------------|
| **Real-time Support** | Critical for balance and motion control |
| **DDS Communication** | Reliable data distribution |
| **Multi-platform** | Works on embedded systems (Jetson) |
| **Large Ecosystem** | Extensive packages for perception, planning |
| **Industry Adoption** | Standard in robotics industry |

### Quick ROS 2 Installation

```bash
# Add ROS 2 repository
sudo apt update && sudo apt install -y software-properties-common
sudo add-apt-repository universe
sudo apt update && sudo apt install curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# Install ROS 2 Humble
sudo apt update
sudo apt install ros-humble-desktop

# Source ROS 2
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

## Key Concepts Preview

### Nodes
The basic building blocks - independent processes that perform computation.

### Topics
Named buses for publish/subscribe communication between nodes.

### Services
Request/response communication for synchronous operations.

### Actions
Long-running tasks with feedback and cancellation support.

### Parameters
Runtime configuration values for nodes.
