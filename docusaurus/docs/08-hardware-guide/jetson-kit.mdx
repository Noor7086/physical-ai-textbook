# Jetson Development Kit

The NVIDIA Jetson platform is the standard edge compute platform for robotics AI. It brings GPU-accelerated inference to size, weight, and power (SWaP) constrained environments -- exactly where robots operate. This chapter covers selecting, flashing, configuring, and benchmarking Jetson devices for physical AI workloads.

## Learning Objectives

By the end of this chapter, you will be able to:

1. **Choose** the right Jetson module for your project requirements
2. **Flash** a Jetson device with JetPack SDK
3. **Configure** the device for ROS 2 and AI inference
4. **Connect** cameras, IMUs, and other peripherals
5. **Run** ROS 2 nodes on Jetson with GPU-accelerated inference
6. **Benchmark** inference performance across different model architectures

## Jetson Orin Platform Comparison

NVIDIA offers several Jetson Orin modules targeting different performance and cost points. For physical AI learning, the Orin Nano and Orin NX are the most relevant.

## Step 1: Flashing with JetPack SDK

JetPack is NVIDIA's SDK for Jetson. It includes the Linux kernel, CUDA, cuDNN, TensorRT, and multimedia APIs, all pre-integrated.

### Option A: SDK Manager (Recommended)

The NVIDIA SDK Manager runs on your development workstation (Ubuntu 22.04 or 20.04) and flashes the Jetson over USB.

```bash
# On your WORKSTATION (not the Jetson):

# 1. Download SDK Manager from NVIDIA Developer site
# https://developer.nvidia.com/sdk-manager

# 2. Install it
sudo apt install -y ./sdkmanager_*_amd64.deb

# 3. Connect Jetson to workstation via USB-C
# Put Jetson in recovery mode:
#   - Hold RECOVERY button
#   - Press and release RESET button
#   - Release RECOVERY button after 2 seconds

# 4. Verify Jetson is detected
lsusb | grep -i nvidia
# Should show: NVIDIA Corp. APX

# 5. Launch SDK Manager
sdkmanager
```

In the SDK Manager GUI:
1. Select your Jetson model (Orin Nano or Orin NX)
2. Select JetPack 6.0 (latest)
3. Accept licenses
4. Choose storage target (NVMe SSD recommended over SD card)
5. Click "Flash" and wait (~15-30 minutes)

### Option B: Command-Line Flashing

For headless or automated setups:

```bash
# Download L4T (Linux for Tegra) BSP
wget https://developer.nvidia.com/downloads/embedded/l4t/r36_release_v3.0/release/jetson_linux_r36.3.0_aarch64.tbz2
wget https://developer.nvidia.com/downloads/embedded/l4t/r36_release_v3.0/release/tegra_linux_sample-root-filesystem_r36.3.0_aarch64.tbz2

# Extract
sudo tar xpf jetson_linux_r36.3.0_aarch64.tbz2
cd Linux_for_Tegra/rootfs/
sudo tar xpf ../../tegra_linux_sample-root-filesystem_r36.3.0_aarch64.tbz2
cd ..

# Apply binaries
sudo ./apply_binaries.sh

# Flash (Jetson must be in recovery mode)
# For Orin Nano:
sudo ./flash.sh jetson-orin-nano-devkit nvme0n1p1
```

## Step 2: Initial System Configuration

After flashing, boot the Jetson with a monitor, keyboard, and mouse attached.

### First Boot Setup

The Ubuntu-based setup wizard will guide you through language, timezone, user account, and network. After completing it:

```bash
# Update the system
sudo apt update && sudo apt upgrade -y

# Verify JetPack version
cat /etc/nv_tegra_release
# Expected: # R36 (release), REVISION: 3.0, ...

# Check CUDA is pre-installed
nvcc --version
# Expected: Cuda compilation tools, release 12.2, V12.2.xxx

# Verify GPU with a quick test
/usr/local/cuda/extras/demo_suite/deviceQuery
```

### Maximize Performance Mode

```bash
# Set to maximum performance mode (MAXN)
sudo nvpmodel -m 0

# Enable all CPU cores at maximum frequency
sudo jetson_clocks

# Verify power mode
nvpmodel -q
# Expected: NV Power Mode: MAXN
```

### Configure Swap Space

Jetson devices have limited RAM. Adding swap prevents out-of-memory kills during model loading:

```bash
# Create a 4 GB swap file (adjust size based on your workload)
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Make persistent across reboots
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# Verify
free -h
```

### Camera Node Example

```python
#!/usr/bin/env python3
"""jetson_camera_node.py -- Publish camera frames with GPU-accelerated processing."""
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import cv2
import numpy as np

class JetsonCameraNode(Node):
    def __init__(self):
        super().__init__('jetson_camera')

        # GStreamer pipeline for CSI camera with hardware acceleration
        # For USB camera, use: cv2.VideoCapture(0)
        gst_pipeline = (
            "nvarguscamerasrc ! "
            "video/x-raw(memory:NVMM),width=640,height=480,framerate=30/1 ! "
            "nvvidconv ! video/x-raw,format=BGRx ! "
            "videoconvert ! video/x-raw,format=BGR ! "
            "appsink drop=1"
        )
        self.cap = cv2.VideoCapture(gst_pipeline, cv2.CAP_GSTREAMER)

        if not self.cap.isOpened():
            self.get_logger().error("Failed to open camera")
            return

        self.publisher = self.create_publisher(Image, '/camera/image_raw', 10)
        self.bridge = CvBridge()
        self.timer = self.create_timer(1.0 / 30.0, self.publish_frame)
        self.frame_count = 0

        self.get_logger().info("Jetson camera node started (30 FPS)")

    def publish_frame(self):
        ret, frame = self.cap.read()
        if not ret:
            self.get_logger().warn("Frame capture failed")
            return

        msg = self.bridge.cv2_to_imgmsg(frame, encoding='bgr8')
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.header.frame_id = 'camera_link'
        self.publisher.publish(msg)

        self.frame_count += 1
        if self.frame_count % 100 == 0:
            self.get_logger().info(f"Published {self.frame_count} frames")

    def destroy_node(self):
        self.cap.release()
        super().destroy_node()

def main(args=None):
    rclpy.init(args=args)
    node = JetsonCameraNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

### TensorRT Inference Node

```python
#!/usr/bin/env python3
"""jetson_detector_node.py -- Object detection with TensorRT on Jetson."""
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from vision_msgs.msg import Detection2DArray, Detection2D, ObjectHypothesisWithPose
from cv_bridge import CvBridge
import numpy as np
import tensorrt as trt
import pycuda.driver as cuda
import pycuda.autoinit
import time

class TensorRTDetector(Node):
    def __init__(self):
        super().__init__('tensorrt_detector')

        # Load TensorRT engine
        self.declare_parameter('engine_path', 'model.engine')
        engine_path = self.get_parameter('engine_path').value

        self.logger = trt.Logger(trt.Logger.WARNING)
        with open(engine_path, 'rb') as f:
            runtime = trt.Runtime(self.logger)
            self.engine = runtime.deserialize_cuda_engine(f.read())
        self.context = self.engine.create_execution_context()

        # Allocate GPU buffers
        self.inputs, self.outputs, self.bindings, self.stream = \
            self._allocate_buffers()

        self.bridge = CvBridge()
        self.subscription = self.create_subscription(
            Image, '/camera/image_raw', self.detect_callback, 10
        )
        self.detection_pub = self.create_publisher(
            Detection2DArray, '/detections', 10
        )

        self.get_logger().info(f"TensorRT detector loaded: {engine_path}")

    def _allocate_buffers(self):
        """Allocate host and device memory for TensorRT engine."""
        inputs, outputs, bindings = [], [], []
        stream = cuda.Stream()

        for i in range(self.engine.num_io_tensors):
            name = self.engine.get_tensor_name(i)
            shape = self.engine.get_tensor_shape(name)
            dtype = trt.nptype(self.engine.get_tensor_dtype(name))
            size = trt.volume(shape)
            host_mem = cuda.pagelocked_empty(size, dtype)
            device_mem = cuda.mem_alloc(host_mem.nbytes)
            bindings.append(int(device_mem))

            if self.engine.get_tensor_mode(name) == trt.TensorIOMode.INPUT:
                inputs.append({'host': host_mem, 'device': device_mem})
            else:
                outputs.append({'host': host_mem, 'device': device_mem})

        return inputs, outputs, bindings, stream

    def detect_callback(self, msg):
        """Run inference on incoming camera frame."""
        start = time.monotonic()

        frame = self.bridge.imgmsg_to_cv2(msg, 'bgr8')
        # Preprocess: resize, normalize, transpose to NCHW
        input_img = self._preprocess(frame)

        # Copy to GPU, run inference, copy results back
        np.copyto(self.inputs[0]['host'], input_img.ravel())
        cuda.memcpy_htod_async(
            self.inputs[0]['device'], self.inputs[0]['host'], self.stream
        )
        self.context.execute_async_v2(
            bindings=self.bindings, stream_handle=self.stream.handle
        )
        for out in self.outputs:
            cuda.memcpy_dtoh_async(out['host'], out['device'], self.stream)
        self.stream.synchronize()

        elapsed_ms = (time.monotonic() - start) * 1000
        self.get_logger().info(
            f"Inference: {elapsed_ms:.1f}ms", throttle_duration_sec=2.0
        )

    def _preprocess(self, frame, input_size=(640, 640)):
        """Resize and normalize frame for YOLO-style models."""
        import cv2
        img = cv2.resize(frame, input_size)
        img = img.astype(np.float32) / 255.0
        img = np.transpose(img, (2, 0, 1))  # HWC -> CHW
        img = np.expand_dims(img, axis=0)    # Add batch dim
        return np.ascontiguousarray(img)

def main(args=None):
    rclpy.init(args=args)
    node = TensorRTDetector()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Step 6: Performance Benchmarks

### Converting Models to TensorRT

TensorRT optimizes models for Jetson hardware. Convert your ONNX models:

```bash
# Convert ONNX model to TensorRT engine
# FP16 mode gives ~2x speedup on Orin with minimal accuracy loss
/usr/src/tensorrt/bin/trtexec \
    --onnx=yolov8n.onnx \
    --saveEngine=yolov8n_fp16.engine \
    --fp16 \
    --workspace=1024 \
    --verbose

# INT8 mode gives best performance (requires calibration data)
/usr/src/tensorrt/bin/trtexec \
    --onnx=yolov8n.onnx \
    --saveEngine=yolov8n_int8.engine \
    --int8 \
    --calib=calibration_cache.bin \
    --workspace=1024
```

### Power vs Performance Tradeoffs

```python
#!/usr/bin/env python3
"""benchmark_power_modes.py -- Compare inference across Jetson power modes."""
import subprocess
import time
import numpy as np

POWER_MODES = {
    "15W": 0,   # MAXN for Orin Nano
    "10W": 1,   # Reduced power
    "7W": 2,    # Minimum power
}

def set_power_mode(mode_id):
    subprocess.run(["sudo", "nvpmodel", "-m", str(mode_id)], check=True)
    time.sleep(2)  # Allow clocks to settle

def run_benchmark(engine_path, iterations=100):
    result = subprocess.run(
        ["/usr/src/tensorrt/bin/trtexec",
         f"--loadEngine={engine_path}",
         f"--iterations={iterations}",
         "--avgRuns=10"],
        capture_output=True, text=True
    )
    # Parse median latency from output
    for line in result.stdout.split('\n'):
        if 'median' in line.lower():
            return line.strip()
    return "Parse error"

if __name__ == "__main__":
    engine = "yolov8n_fp16.engine"
    for name, mode_id in POWER_MODES.items():
        print(f"\n=== Power Mode: {name} ===")
        set_power_mode(mode_id)
        result = run_benchmark(engine)
        print(f"  {result}")
```

## Jetson Tips and Best Practices

1. **Always use NVMe SSD** over SD card. The read/write speed difference (3500 MB/s vs 100 MB/s) dramatically impacts model loading and system responsiveness.

2. **Use FP16 by default.** On Orin's Ampere GPU, FP16 operations run at nearly 2x the speed of FP32 with negligible accuracy loss for most robotics perception tasks.

3. **Monitor thermal throttling.** Jetson will reduce clock speeds when temperature exceeds ~85C. Use a heatsink or active fan.

```bash
# Check current temperature
cat /sys/devices/virtual/thermal/thermal_zone*/temp
# Values are in millidegrees Celsius (e.g., 45000 = 45.0C)
```

4. **Set `MAXN` power mode** during development. You can reduce power for deployment later.

5. **Use headless mode** in production. Disabling the desktop environment frees ~500 MB RAM.

```bash
# Switch to headless mode
sudo systemctl set-default multi-user.target
sudo reboot

# Switch back to desktop if needed
sudo systemctl set-default graphical.target
sudo reboot
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Jetson not detected in recovery mode | Try a different USB-C cable (data cable, not charge-only); try the other USB-C port |
| Boot loop after flash | Re-flash with SDK Manager; ensure power supply is 19V/4.5A |
| `nvcc` not found | Add `/usr/local/cuda/bin` to `$PATH` |
| CSI camera not detected | Check ribbon cable orientation (contacts face the heatsink); run `dmesg \| grep imx` |
| Out of memory during inference | Enable swap (Step 2); reduce batch size; use smaller model |
| Low FPS on inference | Verify you are using TensorRT engine (not raw ONNX); check power mode is `MAXN` |
